JohnTech POS & Inventory (Ongoing)

Capstone project for a full-stack POS and inventory system with role-based authentication, real-time sales and stock tracking for two branches, and automated management tools.

HTML CSS JavaScript PHP MySQL Capstone

Overview

The system centralizes sales, inventory, and branch operations. It supports cashier and admin roles, synchronous stock updates, sales history, and daily sales reports.

Key Features

  • Role-based access: Admin, Cashier
  • Real-time inventory synchronization across two branches
  • Audit log and quick checkout
  • Daily, weekly, and monthly sales reporting

Architecture

Built with PHP and MySQL on a classic MVC structure, enhanced with vanilla JavaScript for interactivity. The system is still in active development and is intended for shared hosting deployment with database backups.
